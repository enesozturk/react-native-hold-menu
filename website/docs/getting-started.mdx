# React Native Hold Menu

A lean, modern hold-to-open context menu for React Native powered by Reanimated 4.

## Requirements

- `react-native >= 0.83`
- `react >= 19.2`
- `react-native-reanimated >= 4`
- `react-native-worklets >= 0.7`
- `react-native-gesture-handler >= 2`
- `expo-blur` and `expo-haptics` installed in the host app

## Installation

```bash
pnpm add react-native-hold-menu react-native-reanimated react-native-worklets react-native-gesture-handler expo-blur expo-haptics
```

## Required setup

1. Wrap your app root in `GestureHandlerRootView`.
2. Add `react-native-worklets/plugin` as the last Babel plugin.
3. Wrap your app tree with `HoldMenuProvider`.

```js
module.exports = {
  presets: ['babel-preset-expo'],
  plugins: ['react-native-worklets/plugin'],
};
```

## What changed in 1.0

- The package no longer depends on `@gorhom/portal`.
- `HoldMenuProvider` no longer renders `GestureHandlerRootView` for you.
- `HoldItem.theme` was removed.
- The package now targets the Reanimated 4 / worklets toolchain.
